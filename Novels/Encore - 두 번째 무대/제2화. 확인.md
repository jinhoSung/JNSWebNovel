# Encore: 두 번째 무대 - 제2화. 확인

새벽 6시 30분.

지호는 여전히 침대에 앉아 있었다. 밤새 자지 않았다. 천장을 계속 바라봤다. 시스템의 파란 창도 여전히 그의 시야 속에 떠 있었다.

눈을 감으면 보였다. 눈을 뜨면 더 선명하게 보였다. 마치 신경망에 직접 입력되고 있는 것처럼.

손가락으로 그 위를 훑어봤다. 창이 손가락을 따라 움직였다. 저항감이 있었다. 마치 물 속에 손을 담그는 것처럼.

현실이었다.

지호는 거울을 다시 봤다. 20살의 얼굴. 하지만 눈빛은 28살의 것이었다. 6년간의 경험과 후회가 그 눈에 담겨 있었다.

기숙사 방문이 열리는 소리가 났다.

준호가 도서관에서 돌아온 것이다. 8시간을 푹 자고 온 사람의 표정이었다.

"야, 아직도 못 자고 있었어? 공부하냐?"

거짓말이었다. 하지만 준호는 의심하지 않았다.

준호는 침대에 누웠다 일어났다 하며 옷을 갈아입었다. 지호는 그의 움직임을 관찰했다. 모든 것이 자연스러웠다. 2022년의 일상이 흘러가고 있었다.

"야, 넌 아이돌 팀 한다고 했잖아? FATE라고?"

같은 질문. 같은 톤. 정해진 대사를 읽는 배우처럼 정확했다.

지호는 침대에서 일어나 앉았다.

"음... 그냥 그래."

"알아, 알아. 대학생 아이돌 이런 거 해서 유튜브에 몇 만 조회수 받고..."

"이따가 팀 만날 거야."

지호의 목소리가 준호의 말을 끊었다. 톤이 달랐다. 예정된 수동성이 아니라, 능동적인 의지가 그 목소리에 담겨 있었다.

준호가 고개를 들었다.

"뭐? 갑자기?"

"응. 뭔가 하고 싶은 게 생겼거든."

"뭐?"

"아직 말할 순 없어."

준호는 웃으며 손을 들었다.

"알았어, 알았어. 비밀이지?"

지호가 고개를 끄덕였다.

준호가 나간 후, 지호는 휴대폰을 들었다. FATE 단체톡을 확인했다.

```
[박준혁: 9월 9일 오후 3시]
요즘 뭐해? 너무 오래 모이지 않은 것 같은데

[이정현: 9월 10일 오전 11시]
아 맞다. 요즘 어떻게 지내? 부모님이 자꾸 음악 집어쳐라고 하는데...

[최민준: 9월 11일 오후 5시]
계획 있으신가요?

[한태윤: 9월 12일 오후 8시]
지호 형 언제 나와요?

[조승윤: 9월 13일 오전 10시]
기다려요!
```

팀원들이 지호를 찾고 있었다. 그리고 지호는 그 메시지들을 무시했다. 아니, 무시하고 있었다.

과거의 지호는 팀에 집착했지만, 동시에 팀을 소홀히 했다. 자신의 음악을 완벽하게 만들겠다는 집착이 팀 전체를 망가뜨렸다.

지호의 손가락이 화면 위를 움직였다.

```
[지호: 오늘 저녁에 찜질방 가지 않을래? 모여서 뭐할지 얘기하고 싶어.]
```

메시지를 보내려는 순간, 반투명한 파란색 창이 나타났다.

```
[STAGE 시스템 - 알림]
메시지 전송이 중대한 변화의 신호입니다.
현재 팀 신뢰도: 50%

이 메시지를 전송하시겠습니까?
[예] [아니오]
```

지호는 주저했다. 손가락이 화면 위에서 떨렸다.

그리고 깨달았다.

이건 꿈이 아니다.

지호는 손가락으로 [예]를 눌렀다.

메시지가 전송되었다.

즉시 답장이 들어왔다.

```
[박준혁: 진짜??? 오!! 가자!!]
[이정현: 오빠! 가요!!]
[최민준: ...네]
[한태윤: 네!!]
[조승윤: 와!! 기다렸어!!]
```

단 5초. 모든 팀원들이 동의했다. 마치 그들이 이 메시지를 기다리고 있었던 것처럼.

지호는 휴대폰을 내렸다.

그리고 천천히 침대에서 일어나 앉았다.

"이번엔... 다를 거야."

중얼거림은 확신으로 변했다.

## 3. 팀 재회의 준비

오후 3시.

지호는 방에서 계획을 세웠다. 노트북을 켜고, 지난 6년간의 기억을 되짚으며.

FATE는 언제 망가지기 시작했을까?

명확했다. 지호의 완벽주의가 팀을 짓누르기 시작했을 때부터였다.

2022년 9월, 팀이 아직 희망을 가지고 있을 때부터 모든 것을 바꿔야 했다.

지호는 각 팀원에 대해 메모했다.

**박준혁**
- 현재: 댄서로서의 자신감 부족
- 과로로 인한 번아웃 위험
- 완벽함을 추구하면서 자신을 망가뜨림
- 해결책: 춤의 자유로움을 되찾게 해주기

**이정현**
- 현재: 부모님의 강압에 시달림
- 음악과 포기 생각 중
- 자신의 음악에 대한 확신 부족
- 해결책: 자신의 목소리가 얼마나 소중한지 깨닫게 해주기

**최민준**
- 현재: 침묵 속에서 음악만 생각하고 있음
- 사람들과의 상호작용 두려움
- 작곡 능력이 뛰어나지만 인정받지 못함
- 해결책: 음악의 가치를 인정해주기

**한태윤**
- 현재: 감수성이 뛰어나지만 표현이 부족
- 자신의 감정을 말로 표현하는 것에 두려움
- 래프 실력이 좋지만 자신감 부족
- 해결책: 감정 표현의 아름다움을 알게 해주기

**조승윤**
- 현재: 남은 막내로서의 책임감만 존재
- 모든 분야에 평범한 성적, 특화된 것이 없다고 생각
- 팀의 일원으로서의 가치를 못 느낌
- 해결책: 다재다능함의 가치를 알게 해주기

지호는 노트북 화면을 바라봤다.

그리고 가장 중요한 것을 깨달았다.

이들이 필요한 것은 음악이 아니었다. 필요한 것은 누군가가 자신들을 믿어주는 것이었다.

지호는 직접 팀원들에게 메시지를 보내기로 결정했다. 단체톡이 아니라, 개인적으로.

오후 5시, 지호는 박준혁에게 카톡을 보냈다.

```
[지호: 준혁아, 시간 되나? 카페에서 만날 수 있을까?]
```

답장이 즉시 들어왔다.

```
[박준혁: 와! 형! 지호가 먼저 연락하다니! 기다려, 5분만에 나갈게!]
```

## 4. 박준혁과의 대면

카페의 한 구석. 두 사람이 마주앉았다.

박준혁의 얼굴은 밝았지만, 눈 아래로는 피로의 흔적이 보였다. 밤새 뭔가를 했던 것 같았다. 안무 창작일 수도, 아니면 걱정일 수도.

"형, 요즘 뭐해? 어제 카톡할 때 뭔가... 달랐어."

지호는 커피를 마시며 대답했다.

"넌 춤에 자신이 없어?"

준혁의 손이 떨렸다.

"어? 어떻게 알았어?"

"그냥... 눈에 보여."

지호가 준혁의 눈을 바라봤다.

"넌 댄서로서 완벽한 실력을 갖추고 있어. 근데 자신이 없다. 왜지?"

준혁이 답변을 피했다. 커피를 마시는 척했다.

"너의 춤은 완벽해. 정말로. 하지만 넌 그걸 몰라."

지호의 목소리가 낮아졌다. 그 낮은 목소리 속에는 6년 간의 경험이 담겨 있었다.

"넌 자신의 춤이 부족하다고 생각하고 있어. 계속 완벽함을 추구해. 그게 결국 널 망가뜨릴 거야."

준혁의 눈가에 눈물이 맺혔다.

"나는... 항상 부족하다고 생각했어. 다른 댄서들에 비해서..."

"그 생각을 그만해. 이번 버스킹에서 넌 너 자신의 춤을 보여 줄 거야. 완벽함이 아니라, 너의 춤을. 알겠어?"

준혁이 고개를 끄덕였다.

그 순간, 시스템이 울렸다.

```
[팀 신뢰도 변화]
박준혁: 48% → 52%

개인 상담 진행도: 1/5
```

## 5. 이정현과의 대면

오후 7시. 다른 카페.

이정현은 휴대폰을 들었다 놨다를 반복했다. 부모님과의 카톡을 확인하고 있었다.

```
[엄마: 정현아, 다음 학기부터 음악과 계속 할 거야? 재생각해봐.]
[아빠: 음악은 취미로만. 취업을 생각해.]
[엄마: 음악은 도박이야. 미안하지만 우리 딸은 안 돼.]
```

카톡이 계속 들어오고 있었다.

지호는 핸드폰을 건네받지 않았다. 정현이를 바라봤다.

"넌 음악이 하고 싶어?"

"네... 정말 하고 싶어요."

"그럼 해. 너의 음악을 위해서."

"아, 근데 부모님이..."

"부모님은 부모님이야. 그들의 인생이 있고, 넌 너의 인생이 있어."

지호가 정현이의 손을 잡았다.

"이번 버스킹에서 넌 너의 보컬로 모두를 감동시킬 거야. 그 영상을 부모님께 보여 줘. 그럼... 부모님도 인정할 수밖에 없을 거야."

정현이의 눈가에 눈물이 맺혔다.

"정말요?"

"응. 난 너를 알아. 너의 보컬은 진짜 대단해."

시스템이 울렸다.

```
[팀 신뢰도 변화]
이정현: 52% → 56%

개인 상담 진행도: 2/5
```

## 6. 최민준과의 대면

오후 9시. 조용한 카페.

최민준은 어색했다. 사람들과 대면하는 것을 좋아하지 않았다. 하지만 지호와는 편했다.

"민준이, 너는 뭘 하고 싶어?"

민준이 작은 목소리로 대답했다.

"음악... 만들고 싶어요."

"그래. 넌 할 수 있어. 너는 음악의 핵심을 아는 사람이야."

민준이가 고개를 들었다.

"형은... 어떻게 알아요? 우리 처음 만났는데..."

"그냥 알아. 너의 눈을 보면... 음악에 대한 사랑이 있어. 그것만으로도 충분해."

지호가 민준의 어깨를 두드렸다.

"이번 버스킹에서 넌 음악의 정신적 핵심을 보여 줄 거야. 그럼 모두가 알게 될 거다. 최민준이라는 뮤지션이 정말 대단하다는 걸."

시스템이 울렸다.

```
[팀 신뢰도 변화]
최민준: 45% → 49%

개인 상담 진행도: 3/5
```

"형, 난 래프를 해 봤는데... 이거 괜찮아?"

```
시간이 흘렀지만 멈추지 마

```

## 8. 조승윤과의 대면

밤 11시. 편의점 앞.

조승윤은 에너지로 가득했다.

"형, 형! 나 어제 생각했어! 여기 부분 봐!"

승윤이가 춤을 추기 시작했다. 작은 공간에서였지만, 그의 동작은 정확했다.

"우와, 승윤아. 이거 정말 멋있는데?"

"정말요? 나는 계속 뭔가 부족한 것 같은데..."

지호가 승윤을 바라봤다.

"넌 부족하지 않아. 넌 다재다능해. 모든 것을 할 수 있어. 그건 개인의 깊이가 아니라 팀의 완성도를 높이는 거야."

"정말요?"

"응. 이번 버스킹에서 넌 모든 파트를 완벽하게 소화할 거야. 그럼 모두가 알게 될 거다. 조승윤이라는 뮤지션이 얼마나 특별한지."

시스템이 울렸다.

```
[팀 신뢰도 변화]
조승윤: 55% → 59%

개인 상담 진행도: 5/5

[메인 퀘스트 진행도]
팀 신뢰도 100% 달성: 15% → 30%

이유: 각 팀원과의 개인 상담 완료

평균 팀 신뢰도: 50% → 54%
```

밤 11시 30분. 지호는 침대에 누웠다.

하지만 자지 않았다. 천장을 바라봤다.

6년 전의 천장이었다. 하지만 이제 그 천장은 희망으로 보였다.

"시작했다."

중얼거린 지호의 목소리에는 확신이 가득했다.

이제부터가 진짜였다.
